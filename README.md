# AI 창작 따라하기

AIEDAP 마스터교원 신규 연수 「AI와 함께하는 교과 혁신: 최신 기술 체험과 적용 실습」(영역1 모듈2)에서 연수에 참여한 선생님들이 강사 화면을 보며 단계별로 따라 하는 웹 페이지입니다.

- **01 이미지 생성 AI**: Quick, Draw!, 잡음 → 그림 데모, Say What You See
- **02 음악 생성 AI**: Blob Opera, Play a Kandinsky, Gemini 음악 생성, Canva에 음악 넣기
- **03 글쓰기 AI**: 다음 토큰 고르기 체험
- **실습: 30초 미래 뉴스**: 대본·자막 → AI Studio TTS 내레이션 → Claude 모션 그래픽 → 편집

체크한 단계와 입력한 내용은 각자의 브라우저에만 저장됩니다.

## 연수생 화면 / 강사 화면 (실시간 동기화)

위쪽 **📚 연수생 · 👨‍🏫 강사** 버튼으로 화면을 바꿉니다.

- **연수생 화면** (기본 주소, 로그인 없음): 단계 체크리스트·진행 막대·실습 링크.
  강사가 단계를 옮기면 **자동으로 같은 단계로 이동**하고, 강사가 시작한 **타이머가 똑같이** 보입니다.
- **강사 화면** (`주소?role=instructor`, Firebase 강사 계정으로 로그인)
  - **📡 진행 공유**: 켜 두면 강사가 누른 단계가 연수생 화면에 실시간으로 전달됩니다.
  - **연수생 화면 자동 이동**: 끄면 연수생 화면은 이동하지 않고 위쪽에 “지금 진행 중” 알림만 뜹니다.
  - 활동 **타이머**(일시정지·닫기도 연수생 화면에 반영), **강사 메모**, Say What You See **정답 프롬프트**, **📱 참여 QR**, **로그아웃**
- 차수를 나눠 운영하려면 주소 뒤에 `?room=차수코드`(영문 소문자·숫자·`-`)를 붙입니다. 참여 QR에도 자동으로 들어갑니다.
- `config.js`의 `firebase`가 `null`이면 **체험 모드**입니다. 같은 브라우저의 탭끼리만 동기화되고 강사 화면은 비밀번호 없이 열립니다(공유되는 데이터가 없음).
- 강사 메모를 고치려면 `index.html`에서 `class="tnote only-t"` 상자를 찾아 바꿉니다. `only-t`는 강사 화면에만, `only-s`는 연수생 화면에만 보입니다.

## Firebase 연결 — AIEDAP 웹앱과 같은 프로젝트 사용

이 페이지는 AIEDAP 모듈5 웹앱([ssoonson/aiedap](https://github.com/ssoonson/aiedap))과 같은 Firebase 프로젝트(`aiedap-ce609`)를 씁니다.
`config.js`에는 이미 설정값이 들어 있고, 강사 로그인도 AIEDAP 웹앱에서 쓰던 **같은 강사 계정**으로 합니다.
콘솔에서 아래 세 가지만 하면 됩니다.

1. **규칙 게시** — Firestore > 규칙 탭에 이 저장소의 `firestore.rules` **전체**를 붙여 넣고, `teacher@example.com`을 강사 이메일로 바꾼 뒤 **게시**합니다.
   - 이 파일은 두 웹앱의 규칙을 합친 것입니다. 한쪽 앱의 규칙만 붙여 넣으면 다른 앱이 동작하지 않으니 항상 합친 파일 전체를 게시하세요.
   - aiedap 저장소의 `firestore.rules`도 같은 내용입니다. 어느 쪽을 써도 됩니다.
2. **강사 명단 등록** — Authentication > 사용자에서 강사 계정 행의 **사용자 UID**를 복사합니다.
   Firestore > 데이터 > 컬렉션 시작에서 컬렉션 ID는 `instructors`, 문서 ID는 복사한 UID로 하고, 필드를 하나(예: `name` = `강사`) 넣어 저장합니다.
3. **승인된 도메인** — Authentication > 설정 > 승인된 도메인에 이 페이지 주소의 도메인(예: `ssoonson.github.io`)을 추가합니다.

참고
- 무료(Spark) 요금제의 하루 사용량(읽기 5만 회 등)을 두 웹앱이 나눠 씁니다. 이 페이지는 연수생 한 명이 진행이 바뀔 때마다 1회 정도만 읽어서 사용량이 적습니다.
- 다른 Firebase 프로젝트로 옮기려면 `config.js`의 `firebase` 값을 그 프로젝트 것으로 바꾸고, 위 1~3을 그 프로젝트에서 하면 됩니다. 이 앱만 쓰는 프로젝트라면 `firestore.rules`의 ② 부분만 있어도 됩니다.

## 비밀번호·보안 관리

비밀번호는 **이 저장소 어디에도 없습니다.** `config.js`의 값(apiKey 등)은 공개돼도 되는 프로젝트 식별값이고, 실제 보호는 아래 장치들이 맡습니다.

- **비밀번호 저장**: Firebase Authentication 서버에만 해시로 저장됩니다. 페이지 소스·네트워크 기록으로 알아낼 수 없습니다.
- **강사 판별**: 이메일이 아니라 Firestore `instructors/{UID}` 명단으로 판별합니다. 명단은 콘솔에서만 바꿀 수 있고 웹에서는 강사 본인도 고칠 수 없습니다. 저장소에는 강사 이메일·UID가 들어가지 않습니다.
- **쓰기 권한**: 진행 상태는 명단에 있는 강사만 바꿀 수 있고(규칙으로 강제), 단계 이름·타이머 형식·서버 시각까지 검사합니다. 연수생이 개발자 도구로 직접 써도 거부됩니다.
- **무차별 대입 방지**: 로그인을 여러 번 틀리면 Firebase가 자동으로 잠시 막습니다. 오류 문구는 이메일과 비밀번호 중 무엇이 틀렸는지 알려 주지 않습니다.
- **로그인 유지 범위**: 그 탭에만 유지되고 탭·브라우저를 닫으면 로그아웃됩니다. 공용 PC라면 끝날 때 **로그아웃**을 눌러 주세요. 입력한 비밀번호는 시도 직후 입력칸에서 지워집니다.

콘솔에서 꼭 해 둘 설정:

1. **강한 비밀번호** — 12자 이상, 다른 사이트와 다른 비밀번호를 씁니다. 바꿀 때는 Authentication > 사용자 > 해당 계정 ⋮ > 비밀번호 재설정.
2. **회원가입 막기** — Authentication > 설정 > 사용자 작업에서 **가입(생성) 사용 설정**을 끕니다. (꺼 두지 않아도 명단에 없는 계정은 아무것도 못 하지만, 불필요한 계정 생성을 막습니다.)
3. **이메일 열거 보호** — Authentication > 설정 > 사용자 작업의 **이메일 열거 보호**가 켜져 있는지 확인합니다(새 프로젝트는 기본으로 켜짐).
4. **승인된 도메인 정리** — 쓰지 않는 도메인은 지웁니다.
5. **API 키 사용처 제한(권장)** — Google Cloud 콘솔 > API 및 서비스 > 사용자 인증 정보 > 해당 브라우저 키 > 애플리케이션 제한사항 **HTTP 리퍼러**에 `https://<사용자이름>.github.io/*`를 넣습니다.
6. **(선택) App Check** — Firebase > App Check에서 reCAPTCHA로 이 사이트만 Firestore에 접근하게 할 수 있습니다.

참고: 강사 메모와 정답 프롬프트는 화면에서만 숨겨질 뿐 HTML 소스에는 들어 있습니다. 비밀번호처럼 감춰야 할 내용은 페이지에 적지 마세요.

## 폴더 구성

```
index.html   페이지 전체 (HTML·CSS·JS 한 파일)
img/         페이지에 쓰는 이미지
config.js    Firebase 설정(이 파일만 고치면 됨, 비밀번호는 적지 않음)
firestore.rules  Firestore 보안 규칙(콘솔에 붙여 넣기)
assets/      QR 생성 라이브러리(qrcode.js, MIT)
README.md    이 설명
```

별도 빌드 과정이 없습니다. `index.html`을 브라우저로 열면 체험 모드로 바로 동작합니다.

## GitHub Pages로 공개하기

1. GitHub에서 새 저장소를 만듭니다.
2. 저장소 화면에서 **Add file → Upload files**를 누르고, `index.html`, `config.js`, `firestore.rules`, `README.md`, `img`·`assets` 폴더를 한꺼번에 끌어다 놓은 뒤 **Commit changes**를 누릅니다.
3. **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 고르고 **Save**를 누릅니다.
4. 1~2분 뒤 `https://<사용자이름>.github.io/<저장소이름>/` 주소로 열 수 있습니다.

## 고칠 때

- 문구·단계는 `index.html`에서 찾아 바꾸면 됩니다.
- 이미지를 바꿀 때는 `img/` 안의 같은 이름 파일을 덮어쓰면 됩니다.
- 글꼴은 Google Fonts(Do Hyeon, Noto Sans KR, IBM Plex Mono)에서 불러옵니다.
